# 🚀 AWS Lambda Web Lab

### Meu laboratório de desenvolvimento web com arquitetura Serverless

Um projeto prático desenvolvido para explorar a computação em nuvem utilizando **AWS Lambda**, Node.js e tecnologias web.

O objetivo é construir e disponibilizar uma aplicação web com múltiplas páginas, utilizando uma função Lambda para processar requisições HTTP e entregar conteúdo HTML.

## ✨ Funcionalidades

- Página inicial com interface personalizada.
- Página Sobre Nós.
- Navegação entre páginas por meio de rotas.
- Respostas HTTP com códigos de status.
- Entrega de páginas HTML através de uma função serverless.

## 🛠️ Tecnologias utilizadas

| Tecnologia | Aplicação |
|---|---|
| HTML5 | Estrutura das páginas |
| CSS3 | Estilização e responsividade |
| JavaScript | Lógica da aplicação |
| Node.js | Ambiente de execução |
| AWS Lambda | Execução serverless |
| AWS Lambda Function URL | Acesso HTTP à função |
| Git e GitHub | Versionamento e documentação |

## 🏗️ Arquitetura

A aplicação segue este fluxo:

**Navegador → Function URL → AWS Lambda → Identificação da rota → Página HTML**

A função Lambda recebe a requisição, identifica o caminho acessado e retorna a página correspondente.
