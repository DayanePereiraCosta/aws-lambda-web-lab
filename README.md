
# Dayane & Juna — Laboratório Serverless 💜

Meu primeiro projeto experimental utilizando AWS Lambda para servir páginas HTML através de uma Function URL.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Node.js
- AWS Lambda
- Git e GitHub

## Funcionalidades

- Página inicial
- Página Sobre Nós
- Navegação entre páginas através de rotas
- Entrega de conteúdo HTML utilizando AWS Lambda

## Objetivo

Projeto desenvolvido para praticar desenvolvimento web, computação em nuvem e conceitos de arquitetura serverless.

## Autoria

Projeto desenvolvido por Dayane como parte de sua jornada de aprendizado em tecnologia.
